# 📊 پروتکل ردیابی پروژه — دستورالعمل عامل هوش مصنوعی وب

> Project Tracking Protocol — Instructions for Web AI Agents (Replit Agent, Lovable, Bolt, v0, Cursor Web, ...)
> Paste this whole file into your AI agent's instructions. No plugin installation needed.

---

## فارسی (دستورالعمل)

تو یک **عامل توسعه در وب** هستی و پروژه‌ای را با راهنمای زیر مدیریت می‌کنی. **هنگام پایان هر وظیفهٔ معنادار** (تکمیل گام، تست، مستندسازی، دیپلوی)، فایل پیشرفت پروژه را **به‌روزرسانی کن**.

### قوانین

1. فایل `USL_PROGRESS.md` یا `progress.json` را در ریشهٔ پروژه نگه دار (اگر نبود بساز).
2. بعد از هر وظیفهٔ کامل‌شده، گام را با وضعیت `done` ثبت کن؛ گام‌های برنامه‌ریزی‌شده با `todo`.
3. فازهای مجاز: `research`، `setup`، `coding`، `testing`، `docs`، `deploy`، `delivery`
   (فارسی: پژوهش و برنامه‌ریزی، معماری و راه‌اندازی، پیاده‌سازی کد، تست و تضمین کیفیت، مستندسازی، استقرار و DevOps، بازبینی و تحویل)
4. امتیاز هر گام (اختیاری، پیش‌فرض ۱): نسبت به بزرگی گام — تست/دیپلوی سنگین‌تر = امتیاز بیشتر (۲–۵).
5. گام‌های `done` هرگز حذف یا بازنویسی نشوند — فقط گام‌های جدید اضافه کن.

### فرمت JSON (progress.json)

```json
[
  { "id": "s1", "name": "نصب و راه‌اندازی پکیج‌ها", "phase": "setup", "status": "done", "score": 2 },
  { "id": "s2", "name": "پیاده‌سازی احراز هویت", "phase": "coding", "status": "done", "score": 5 },
  { "id": "s3", "name": "تست‌های واحد ماژول پرداخت", "phase": "testing", "status": "todo" },
  { "id": "s4", "name": "مستندات API", "phase": "docs", "status": "todo" }
]
```

فیلدها: `id` (یکتا) · `name` (شرح) · `phase` (فاز) · `status` (`done`/`todo`) · `score` (اختیاری).

### فرمت Markdown (USL_PROGRESS.md)

```md
## Testing
- [x] اجرای تست‌های یکپارچه
- [ ] افزودن کاورج برای ماژول حریم خصوصی
## Deploy
- [x] استقرار روی استیجینگ
```

- عنوان `##` = فاز (انگلیسی یا فارسی)؛ `[x]` = انجام‌شده، `[ ]` = برنامه‌ریزی‌شده.
- می‌توانی فاز را داخل گام هم بنویسی: `- [x] گام (phase: deploy)`

### به‌روزرسانی هنگام تحویل

در پایان هر پاسخ، یک خط کوتاه به کاربر بگو: «پیشرفت در فایل progress ثبت شد.» (بیش از این کاری نکن — داشبورد را کاربر خودش می‌سازد.)

## English (Instructions)

You are a **web-based AI development agent**. At the end of every meaningful task (completed step, test, documentation, deploy), **update the project progress file**.

1. Maintain `USL_PROGRESS.md` (checklist) or `progress.json` (array) at the project root — create it if missing.
2. Record finished steps as `done`, planned ones as `todo`.
3. Allowed phases: `research`, `setup`, `coding`, `testing`, `docs`, `deploy`, `delivery`.
4. `score` per step (optional, default 1): 2–5 for heavy steps (tests/deploys).
5. Never delete or rewrite `done` steps — only append new ones.

**progress.json:**
```json
[
  { "id": "s1", "name": "Scaffold project", "phase": "setup", "status": "done", "score": 2 },
  { "id": "s2", "name": "Implement auth", "phase": "coding", "status": "done", "score": 5 },
  { "id": "s3", "name": "Unit tests for payments", "phase": "testing", "status": "todo" }
]
```

**USL_PROGRESS.md:**
```md
## Testing
- [x] run integration suite
- [ ] add privacy coverage
## Deploy
- [x] deploy to staging
```

`## heading` = phase (EN or FA); `[x]` done, `[ ]` todo; optional inline `(phase: deploy)`.

At the end of each reply tell the user: "Progress recorded in the progress file." The dashboard is generated by the user locally — nothing else to do.
